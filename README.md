# Orvella Events Website
Includes customer booking/enquiry forms, SQLite storage, protected admin login and dashboard.

## Run
1. Open the `orvella-events` folder in VS Code.
2. Run `npm install`
3. Copy `.env.example` to `.env`
4. Optionally change the admin credentials in `.env`
5. Run `npm start`
6. Website: http://localhost:3000
7. Admin: http://localhost:3000/admin-login

Default admin:
Username: admin
Password: Orvella@123

Do not publish `.env` or `orvella.db` to GitHub.
